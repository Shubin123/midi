Native VST3 browser experiment

This attempts to execute Intel macOS plugin machine code through an Emscripten-built x86 emulator, entirely in a disposable browser worker. It is not a working native plugin player or a source-code decompiler.

Select a macOS .pkg, a ZIP containing one .vst3 bundle, or the executable inside Contents/MacOS. Only analyze plugins you are authorized to use. No installer scripts run; no licensing checks are bypassed.

Normal startup runs initializers and stops at the first missing macOS dependency. Factory-only mode deliberately skips initialization; its metadata can be incomplete or invalid. Neither mode produces playable audio.

The plugin stays on your machine. The pinned, integrity-checked GPL-2.0 Unicorn.js engine loads locally after npm ci --ignore-scripts, or from jsDelivr if unavailable locally. File parsing and emulation have size and execution limits; this is not a security audit of untrusted plugins.
