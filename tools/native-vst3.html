Native VST3 browser experiment

This attempts to execute Intel macOS plugin machine code through an Emscripten-built x86 emulator, entirely in a disposable browser worker. It is not a working native plugin player or a source-code decompiler.

Select a macOS .pkg, a ZIP containing one .vst3 bundle, or the executable inside Contents/MacOS. Only analyze plugins you are authorized to use. No installer scripts run; no licensing checks are bypassed.

Normal startup runs initializers and bundle entry. The processor probe attempts the real component and audio interfaces; the render probe processes a bounded quarter-second note offline and offers a WAV preview only if processing succeeds. This is not realtime MIDI playback. Unsupported macOS dependencies stop execution explicitly. Arcade currently stops during component creation at the unimplemented Cocoa notification center. Factory-only mode deliberately skips initialization; its metadata can be incomplete or invalid.

The plugin stays on your machine. The patched, integrity-checked GPL-2.0 Unicorn.js engine loads from vendor/unicorn, which includes its corresponding source and license. No CDN or dependency installation is required. File parsing and emulation have size and execution limits; this is not a security audit of untrusted plugins.
